## v0.20.0 - 2026-10-02
### Added
* Time filtering support when timelining cli artifacts
* XML output support
* Parquet output support
* Support for setting logging level from the artemis cli
* Support for distributing as Arch Linux package
* Major improvement to reading and accessing data for forensic parsing using new Accessor workflow
* Support for parsing artifacts in zip files
* Sqlite output support
* Optional duckdb output support. Disabled by default
### Changed
* Bumped artifact timestamp precision to milliseconds if supported
* Additional feature flags when compiling artemis
* Major overhaul to the artemis output workflow
* Moved from plaintext log file to jsonl logging via tracing crate
* Additional logging for some Windows artifacts
* Faster MFT parsing
* Faster UsnJrnl parsing
* Faster Registry parsing
* Updated files artifact to support different types of filelistings
### Removed
* Moved macOS ExecPolicy to Artemis API only
* Removed xml2json crate
* Moved Emond parsing to Artemis API only
### Dependencies
* Removed log and simplelog crates
* Added tracing and tracing-subscriber
* Optional duckdb. Disabled by default
### ArtemisApi
* Support for parsing Arch Linux Pacman packages
* Include Firefox snap package for Firefox artifacts
* Extract website permissions from Firefox
